## 新增作业改为灰色占位提示（已实现）

需求：点「添加一条作业」时不再把「在这里输入作业内容」写成正文，改为编辑框里的灰色提示，不实际输入。

改动（7 个文件）：
- `Services/ProjectState.cs`：新增 `HomeworkState.PlaceholderText` 常量（唯一来源）与 `ClearLegacyPlaceholder()`；旧数据里 `Content.Trim()` 恰好等于提示文案时清空 `Content`+`RtfContent`，含提示字样的真实作业不动。
- `Services/AutofillService.cs`：删掉 `AutofillService.PlaceholderHomework`（改引用 `HomeworkState.PlaceholderText`），`IsRecordable` 里的过滤保留为旧数据/粘贴防护。
- `Controls/SubjectTileControl.cs`：`AddHomework()` 改为 `new HomeworkEntry()`；`CreateRichEditor` 设 `PlaceholderText = _isEditing ? HomeworkState.PlaceholderText : string.Empty`（查看模式不显示）；`ApplyDefaultBodyStyle` 的调用条件去掉 `Content.Length > 0`，让空作业也写入默认正文格式（决定用户接着输入的字体字号颜色）。
- `ViewModels/MainViewModel.cs`：`AddHomework()` 同样建空条目。
- `Services/AppDataStore.cs`：`RestoreSubjects` 里逐条 `ClearLegacyPlaceholder()`（projects.json 与 .pch 导入都走这里）。
- `Themes/ThemeResources.xaml`：Dark/Light 各加 3 个 `TextControlPlaceholderForeground`（+PointerOver/Focused）= `BoardTextMutedBrush` 色（#737386 / #747486）。**RichEditBox 没有 `PlaceholderForeground` 属性**（编译报 CS0117），模板里占位色走 `{ThemeResource TextControlPlaceholderForeground}`，所以只能从主题字典覆盖。注意这会同时影响设置页等所有输入框的占位色。
- `tests/SettingsLogic/Program.cs` 加 3 条断言；`tests/verify-interaction-contract.ps1` 加一条契约检查（含 `$themeXaml`）。

### 环境坑（重要，下次直接用）
- 本机 `dotnet` 是 SDK 10.0.401，**`dotnet restore` 会失败**：`NuGet.targets(782,5): error : Value cannot be null. (Parameter 'path1')`。所有 `dotnet build/run` 都要加 `--no-restore`（`obj/project.assets.json` 已存在）。
- `tests/verify-*.ps1` **在本机 Windows PowerShell 5.1 下无法运行**：ANSI 代码页 936，而这些脚本是无 BOM 的 UTF-8 且含中文 → 解析出 90+ 个 ParseException（原版脚本同样如此，非改动引入）。本机没有 PowerShell 7。绕过办法：用 `[System.Management.Automation.Language.Parser]::ParseInput($code, ...)` 显式以 UTF-8 读入再解析，可验证语法（0 错误即通过）；契约条件的实际匹配用 grep 逐条核对。
- PowerShell 工具会吞掉 stdout/stderr，只回传退出码；`& script.ps1` 里的 `exit 1` 会直接结束会话，写在它后面的重定向不会执行。临时诊断要插在 `exit` 之前。另外 `@() | Out-File x` 不会创建文件。
